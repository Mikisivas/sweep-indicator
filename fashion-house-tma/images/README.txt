Board of Trustees images
========================

trustees.html expects the four board card images in this folder with
exactly these filenames:

  terkula-paul-terfa.jpg   Terkula Paul Terfa — Founder & Chairman
  maryam-iorfa.jpg         Maryam Iorfa — Executive Director
  tola-adebayo.jpg         Tola Adebayo — Creative Director
  emeka-nwachukwu.jpg      Emeka Nwachukwu — Chief Account Officer

Save each picture with its matching name (JPEG format) and the page
will pick them up automatically — no code changes needed.
